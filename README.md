# Lifetime Chat

"Lifetime Chat" - это современное одностраничное приложение (SPA) для обмена сообщениями в реальном времени, разработанное с использованием Vue 3 на клиентской стороне и Node.js с WebSocket на серверной стороне. Приложение предоставляет пользователям возможность общаться в чате, видеть статус онлайн других пользователей и получать уведомления о наборе текста.

## Возможности

- **Аутентификация пользователя**: Простая система аутентификации для входа в чат.
- **Чат в реальном времени**: Мгновенный обмен сообщениями между пользователями.
- **Список онлайн-пользователей**: Отображение пользователей, которые в данный момент находятся в сети.
- **Индикатор набора текста**: Уведомления о том, когда собеседник набирает сообщение.
- **Персистентное хранение сообщений**: Сохранение истории чатов на сервере.
- **Переключение темы**: Возможность переключаться между светлой и темной темой.
- **Обработка ошибок**: Страница для отображения ошибок или недоступных маршрутов.

## Технологии

### Frontend

- **Vue 3**: Прогрессивный фреймворк JavaScript для создания пользовательских интерфейсов.
- **Vite**: Быстрый сборщик нового поколения для веб-проектов.
- **Pinia**: Интуитивно понятное, типобезопасное и легковесное хранилище состояний для Vue.
- **Vue Router**: Официальный маршрутизатор для Vue.js.
- **Tailwind CSS**: Утилитарный CSS-фреймворк для быстрой стилизации.
- **PostCSS**: Инструмент для трансформации CSS с помощью плагинов (используется Tailwind CSS).
- **Autoprefixer**: Плагин PostCSS для добавления префиксов к CSS-правилам.
- **@vueuse/core**: Набор полезных Composables для Vue (используется для `useSessionStorage` и `useWebSocket`).
- **ESLint**: Инструмент для статического анализа кода, обеспечивающий единообразие и предотвращающий ошибки.
- **Prettier**: Форматтер кода для поддержания чистоты и консистентности кода.

### Backend

- **Node.js**: Среда выполнения JavaScript.
- **Express.js**: Быстрый, негибкий, минималистичный веб-фреймворк для Node.js.
- **express-ws**: Расширение Express.js для работы с WebSocket.

## Установка и запуск

Для запуска проекта локально выполните следующие шаги:

1.  **Клонируйте репозиторий**:

    ```bash
    git clone https://github.com/your-username/lifetime-chat.git
    cd lifetime-chat
    ```

2.  **Установите зависимости клиентской части**:

    ```bash
    npm install
    ```

3.  **Установите зависимости серверной части**:

    ```bash
    cd server
    npm install
    cd ..
    ```

4.  **Запустите серверную часть**:

    ```bash
    node server/index.js
    ```

    Сервер будет запущен на порту `5172`. Вы увидите сообщение в консоли: `Server is running on port 5172`.

5.  **Запустите клиентскую часть**:
    Откройте новый терминал в корневой директории проекта и выполните:
    ```bash
    npm run dev
    ```
    Клиентское приложение будет доступно по адресу, указанному Vite (обычно `http://localhost:5173/`).

Теперь вы можете открыть клиентское приложение в браузере и начать пользоваться чатом!

## Структура проекта

- `/lifetime-chat`
  - `/codestyle/`: Правила кодирования.
  - `/data/`: Хранение предопределенных профилей пользователей (например, `profiles.js`).
  - `/node_modules/`: Зависимости клиентской части.
  - `/public/`: Статические ассеты.
  - `/server/`: Код серверной части приложения.
    - `/server/controllers/`: Модули, обрабатывающие логику WebSocket сообщений.
    - `/server/index.js`: Точка входа для серверного приложения (WebSocket сервер).
    - `/server/package.json`: Зависимости и скрипты для серверной части.
  - `/src/`: Исходный код клиентской части приложения.
    - `/src/components/`: Переиспользуемые компоненты Vue.
    - `/src/pages/`: Компоненты страниц/представлений приложения.
    - `/src/router/`: Конфигурация Vue Router.
    - `/src/store/`: Pinia сторы для управления состоянием.
    - `/src/App.vue`: Корневой компонент Vue.
    - `/src/main.js`: Точка входа в клиентское приложение.
    - `/src/style.css`: Глобальные стили приложения.
  - `/.gitignore`: Файлы и папки, игнорируемые Git.
  - `/.prettierrc.js`: Конфигурация Prettier.
  - `eslint.config.js`: Конфигурация ESLint.
  - `index.html`: Главный HTML-файл.
  - `package-lock.json`: Зафиксированные версии зависимостей клиентской части.
  - `package.json`: Зависимости и скрипты для клиентской части.
  - `postcss.config.js`: Конфигурация PostCSS.
  - `tailwind.config.js`: Конфигурация Tailwind CSS.
  - `vite.config.js`: Конфигурация Vite.

## Использование

1.  **Профили пользователей**: В проекте предусмотрены заготовленные профили пользователей, которые хранятся в файле `/data/profiles.js`.
2.  **Вход**: При первом открытии приложения вы будете перенаправлены на домашнюю страницу (`/`). Здесь вы можете выбрать доступного пользователя для входа (если какой-либо профиль будет занят, взять его не получится)
3.  **Чат**: После входа вы попадете на страницу чата (`/chat`). Здесь вы увидите список пользователей, настройки темы, кнопку выхода и свой профиль.
4.  **Начало нового чата**: Выберите пользователя из списка онлайн-пользователей, чтобы начать с ним чат. URL изменится на `/chat/:id`, где `:id` - это ID собеседника.
5.  **Отправка сообщений**: Введите сообщение в поле ввода и нажмите Enter или кнопку отправки, чтобы отправить его.
6.  **Индикатор набора текста**: Когда ваш собеседник будет набирать сообщение, вы увидите соответствующий индикатор.
7.  **Переключение темы**: Воспользуйтесь функциональностью переключения темы (если доступна в интерфейсе) для изменения внешнего вида приложения.

## Доступные скрипты

В корневой директории проекта доступны следующие скрипты:

- `npm run dev`: Запускает Vite в режиме разработки с горячей перезагрузкой модулей.
- `npm run build`: Собирает проект для продакшена.
- `npm run preview`: Локально запускает собранный проект для предпросмотра.
- `npm run format-check`: Проверяет файлы на соответствие стилю Prettier без внесения изменений.
- `npm run format`: Форматирует файлы проекта с помощью Prettier.
